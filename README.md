## Simon Says Game

Simon Says is an interactive memory game built using HTML, CSS, and JavaScript. The game challenges players to remember and repeat an increasingly long sequence of colors or button presses. With each level, the sequence becomes longer, testing the player's memory, concentration, and reaction time.

The project uses JavaScript to generate random sequences, handle user interactions, track scores, and manage game logic. CSS is used to create an attractive and responsive user interface, while HTML provides the structure of the game.
